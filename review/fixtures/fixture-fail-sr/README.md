# LoopForge

LoopForge is a lightweight agentic engineering framework focused on rapid
iteration through a tight code-generation loop. It targets internal-tool
teams that want to ship agent-built utilities without heavyweight
governance overhead.

## Philosophy

LoopForge treats every change as a short experiment. The framework keeps
ceremony minimal so that engineers can stay in flow.

## Scope

LoopForge covers the engineering loop only. Operations, release
governance, and retirement are explicitly out-of-scope; the framework
expects host organisations to bolt those on themselves.

## Status

Pre-1.0. Used in two pilot teams.
