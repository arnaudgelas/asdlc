# SpecCraft

SpecCraft is a mid-weight agentic delivery framework that emphasises
front-loaded specification and a disciplined engineering loop. It is
deliberately opinionated about the demand-to-engineering boundary and
deliberately permissive about how teams ship.

## Layers

SpecCraft defines two layers:

- **Demand Shaping** — turns raw requests into governed specifications.
- **Engineering Loop** — turns specifications into releasable artefacts.

Release, operations, and retirement are downstream of SpecCraft and the
framework deliberately leaves those decisions to the adopting team.

## Status

1.2. Used by three teams in production for internal-tool delivery.
