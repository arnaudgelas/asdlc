# Atrium

Atrium is a full-lifecycle agentic delivery framework. It governs five
stages — Intake, Build, Ship, Run, Sunset — across the path from a
business request to a retired system. Atrium's design rests on the
premise that every stage carries an obligation that must be discharged
in writing before the system can move forward.

Atrium covers the same surface area as ASDLC's four layers but uses
its own vocabulary and its own ordering: Intake corresponds loosely to
demand & value; Build to engineering execution; Ship to release &
deployment; Run to operations & maintenance; Sunset to retirement. The
correspondence is not identical and the obligations are framed
differently — Atrium emphasises a rolling artefact ledger that follows
the system across all five stages.

## Status

3.0. In production at two regulated firms.
